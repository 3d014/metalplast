# Metalplast

Website for **Metalplast** — manufacturer and installer of PVC and aluminum windows, doors, and fences. Located in Brčko, Bosnia and Herzegovina, with over 20 years of experience.

**Address:** Suljagića Sokak 17, Brčko, BiH 76100  
**Phone:** +387 61 152 357  
**Email:** info@metalplast.ba

## Tech Stack

- **Next.js 15** — App Router, Server Components, Server Actions
- **TypeScript**
- **Tailwind CSS**
- **Framer Motion** — animations
- **next-intl** — Bosnian / English / German
- **Resend** — contact form emails

## Getting Started

```bash
npm install
npm run dev
```

Create `.env.local`:

```env
RESEND_API_KEY=your_resend_api_key
NEXT_PUBLIC_SITE_URL=https://metalplast.ba
```
